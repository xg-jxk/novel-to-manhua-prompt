## 字段说明

- **镜号**：三位数编号，从 001 开始
- **场景组（scene_id）**：同一场景的镜头填同一个标识（如 `cafe`、`office`、`street_night`）。
  脚本会自动让同组第二个镜头起继承首镜头的环境描述，避免背景漂移。
- **景别**：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- **运镜**：固定 / 推 / 缓慢推近 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 环绕 / 手持 / 骤停 / 慢动作
- **视角（view_angle）**：平视 / 俯视 / 仰视 / 过肩 / 第一人称（POV）
- **角色动作表情（action）**：具体、可视觉化的肢体动作和微表情，如「低头吹咖啡，睫毛低垂」「攥紧拳头，指节发白」
  - 避免抽象词：不要写「很生气」，写「眉头紧皱，咬牙切齿」
- **环境/场景描述（scene_desc）**：同一场景首镜头写完整，后续镜头留空即可自动继承；如有变化再写
- **台词/旁白**：本镜头对应的台词或旁白，没有就写「无」
- **时长(s)**：建议 3-8 秒，对话戏按语速估算（每秒 3-4 字）
- **情绪（mood）**：用于自动匹配光影氛围，如 温柔 / 震惊 / 孤独 / 暧昧 / 爽感 / 悬疑 / 悲伤
- **出场角色**：本镜头出现的角色名，多个用英文逗号分隔，顺序决定左右站位锚定

---

## 填写原则

1. **动作和环境分开写**：action 写角色在做什么，scene_desc 写环境里有什么，不要混在一起
2. **同场景复用 scene_id**：减少重复描述，也保证环境一致性
3. **情绪词要具体**：越具体，光影匹配越准（「温柔思念」比「温柔」更准）
