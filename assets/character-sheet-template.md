# 角色卡模板

> 复制此模板，为每个主要角色填写一张。填写完成后，后续镜头提示词会按景别自动裁剪锁词。
> JSON 格式导出：
> ```json
> {
>   "苏晚": {
>     "age": "25岁左右",
>     "gender": "女",
>     "face_lock": "杏仁眼，鹅蛋脸，皮肤白皙，左眼下方有一颗小泪痣",
>     "hair_lock": "黑色长直发，齐刘海，发尾自然微卷",
>     "body_lock": "身材纤细，身高165cm左右",
>     "outfit": "米白色针织衫，浅蓝色牛仔裤，白色帆布鞋",
>     "style": "韩漫美女脸，唯美厚涂风"
>   }
> }
> ```

## 角色：{姓名}

**基础设定**
- 年龄感（age）：25岁左右 / 30岁左右 / 少年感 / 成熟感
- 性别（gender）：男 / 女
- 气质标签：清冷 / 阳光 / 腹黑 / 温柔 / 霸气 / 柔弱

**锁词（按景别自动裁剪，禁止自由改写）**
- 面部锁词（face_lock）：丹凤眼，鹅蛋脸，皮肤白皙，左眼下方有一颗小泪痣
  - 特写/大特写镜头**只会用这一行**，务必写精
- 发型锁词（hair_lock）：黑色长直发，齐刘海，发尾自然微卷
- 体型锁词（body_lock）：身材纤细，身高165cm左右
  - 全景/远景镜头才会用到这一行

**服装锁词（outfit）**
- 米白色针织衫，浅蓝色牛仔裤，白色帆布鞋
- （多套服装时，按场景换 outfit 值，不要在一个角色卡里塞多套）

**风格关键词（style）**：韩漫美女脸，唯美厚涂风

---

## 为什么要拆成 face_lock / hair_lock / body_lock？

AI 生图时，提示词越长越抓不住重点。我们按景别自动裁剪：

| 景别 | 实际拼进提示词的锁词 |
|------|----------------------|
| 特写 / 大特写 | 只用 face_lock + hair_lock（脸和头发） |
| 中近景 / 中景 | face_lock + outfit（脸和上半身服装） |
| 全景 / 远景 | 全部锁词（全身 + 体型 + 服装） |

这样大特写镜头不会被"身高165cm"这种无关词干扰，全景镜头也不会漏了体型。

## 填写示例

### 角色：苏晚
- age：25岁左右
- gender：女
- face_lock：杏仁眼，鹅蛋脸，皮肤白皙，鼻梁小巧，嘴唇淡粉色，左眼下方一颗小泪痣
- hair_lock：黑色长直发，齐刘海，发尾自然微卷
- body_lock：身材纤细，身高165cm左右
- outfit：燕麦色宽松毛衣，深色牛仔裤，白色帆布鞋
- style：韩漫美女脸，唯美厚涂风，温柔坚韧感
