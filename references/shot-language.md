## 景别选择决策表

| 剧情需要 | 推荐景别 | 理由 |
|----------|----------|------|
| 交代环境/地点 | 大远景 → 远景 | 建立空间感 |
| 人物出场亮相 | 全景 → 中景 | 展示全身造型和气场 |
| 日常对话 | 中近景 | 兼顾表情和手势 |
| 情绪爆发/哭戏/怒戏 | 特写 / 大特写 | 放大情绪冲击力 |
| 内心独白/思考 | 近景 | 聚焦面部微表情 |
| 动作戏/打斗 | 全景 / 中景 | 看清动作全貌 |
| 关键道具/信物 | 特写 | 强调物品重要性 |
| 转场过渡 | 远景空镜 | 呼吸感 |

### 景别递进原则
情绪升级时，景别逐步收紧：
`全景 → 中景 → 近景 → 特写`
对应情绪递进：冷静 → 紧张 → 激动 → 爆发

## 运镜情绪对照表

| 运镜方式 | 情绪/氛围 | 适用场景 |
|----------|-----------|----------|
| 固定镜头 | 平静、客观、日常 | 对话戏、叙事段落 |
| 缓慢推近 | 聚焦、紧张感上升、强调 | 情绪递进、内心发现 |
| 缓慢拉远 | 孤独、苍凉、结局感 | 场景收尾、孤独独白 |
| 左右横摇 | 展示环境、跟随视线 | 新场景介绍、寻找某物 |
| 跟镜头 | 代入感、身临其境 | 走路、奔跑、追逐 |
| 环绕镜头 | 高光时刻、帅气/惊艳 | 角色登场、反转瞬间 |
| 升降镜头 | 气势恢宏、渺小感 | 大场面、人物命运感 |
| 手持晃动 | 紧张、慌乱、纪实感 | 冲突、争吵、突发事件 |

## 竖屏短剧常用节奏

竖屏短剧（9:16）的观众注意力窗口很短，节奏要快：

1. **前3秒必须有钩子**：第一个镜头就要抓住人——要么是冲突画面，要么是悬念特写。
2. **平均镜头时长 3-6 秒**：不要一个镜头超过 8 秒，否则观众划走。
3. **情绪点给特写**：爽点、虐点、反转点，一定要切特写放大情绪。
4. **对话戏正反打**：A说一句切B反应，再切A，不要固定一个镜头拍两个人说话。

## 常见场景的镜头组合套路

### 1. 角色登场（霸气出场）
```
远景空镜（环境）→ 缓慢推近 → 全景（人物全身）→ 中景（上半身）→ 特写（面部/眼神）
运镜：推镜头 + 轻微环绕
```

### 2. 冲突吵架
```
中近景（A愤怒表情）→ 过肩镜头（B视角看A）→ 特写（B攥紧的拳头/红了的眼眶）→ 近景（B反驳）
运镜：手持微晃，节奏加快
```

### 3. 甜蜜互动
```
中景（两人并肩）→ 特写（手牵手）→ 近景（女生害羞低头）→ 特写（男生温柔眼神）
运镜：缓慢推近，柔光
```

### 4. 反转/震惊
```
正常节奏中景 → 突然切大特写（角色瞳孔地震的表情）→ 停顿1秒 → 慢动作
运镜：骤停 + 慢推
```

### 5. 内心独白
```
近景（角色侧脸）→ 空镜（窗外/天空/街道）→ 回到近景（眼神变化）
运镜：固定或缓慢横移
```

## 新手常见错误

1. **全程中景**：没有景别变化，画面单调。必须有远有近、有松有紧。
2. **运镜太花**：一个镜头里又推又摇又环绕，AI生成容易崩。一个镜头只用一种运镜。
3. **台词太长镜头太短**：一句话5个字，镜头时长2秒，观众还没看清就切了。按语速每秒3-4个字估算时长。
4. **忽视空镜**：全是人没有环境，观众不知道在哪。每个场景开头给1-2秒环境空镜。
