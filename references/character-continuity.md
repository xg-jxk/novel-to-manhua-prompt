# 角色一致性规范

> AI 漫剧最大的痛点就是角色脸崩、服装变样。本规范确保全片角色形象统一。

## 核心原则

**角色卡是唯一真相源。** 任何镜头中出现该角色时，外貌和服装描述必须从角色卡原样复制，禁止自由改写、禁止近义词替换。

---

## 角色卡模板

每个新角色首次出场时，按以下模板生成角色卡：

```markdown
### 角色：{姓名/代号}

**基础设定**
- 年龄感：20岁左右 / 30岁左右 / 少年感 / 成熟感
- 性别：男 / 女
- 气质标签：清冷 / 阳光 / 腹黑 / 温柔 / 霸气 / 柔弱

**外貌锁词（必须原样复用，禁止改写）**
- 发型：黑色长直发，齐刘海，发尾微卷 / 银灰色短碎发，刘海遮住左眼
- 面部：丹凤眼，鹅蛋脸，皮肤白皙，嘴角有一颗小痣 / 剑眉星目，下颌线分明，小麦色皮肤
- 体型：身材纤细，身高165cm左右 / 身材挺拔，宽肩窄腰，身高185cm

**服装锁词（每套服装单独列）**
- 日常装：白色衬衫，黑色西装裤，黑色细高跟鞋 / 黑色连帽卫衣，深色牛仔裤，白色运动鞋
- 正式装：黑色修身连衣裙，珍珠项链 / 深灰色西装，白衬衫，黑色领带

**风格关键词**
- 国漫美女脸 / 韩漫帅哥脸 / 日系少女感 / 写实电影脸
```

## 一致性保障规则

### 1. 锁词原样复用（但按景别裁剪）
生成镜头提示词时，角色描述部分直接从角色卡复制粘贴，不要：
- ❌ 把「黑色长直发」改成「乌黑的长头发」
- ❌ 把「丹凤眼」改成「细长的眼睛」
- ❌ 同义改写、润色、补充形容词

**但不是所有镜头都要把锁词全塞进去。** 按景别裁剪，AI 才能抓准重点：

| 景别 | 实际使用的锁词 | 原因 |
|------|----------------|------|
| 特写 / 大特写 | face_lock + hair_lock | 画面只有脸，写「身高165cm」纯浪费 token |
| 中近景 / 中景 | face_lock + outfit | 要看到上半身服装，但体型细节不重要 |
| 全景 / 远景 | face_lock + hair_lock + body_lock + outfit | 全身入镜，所有锁词都要 |

脚本 `batch_generate.py` 已自动按此规则裁剪，手写提示词时也要遵守。

### 2. 服装按场景匹配
- 同一场景内，角色穿同一套衣服，锁词完全一致
- 换场景 = 换装，必须在分镜表中标注「换装」，并从角色卡中选对应服装锁词
- 不要出现「上一个镜头穿白裙子，这个镜头莫名变成黑裙子」的情况

### 3. 同场景环境复用
- 同一场景单元（CSV 里同一个 `scene_id`），首镜头完整描述环境
- 后续镜头环境描述留空，自动继承首镜头，只改光照/天气变化
- 避免每个镜头都自由发挥环境，导致背景漂移

### 4. 多角色空间锚定
- 两个角色同框时，必须在提示词里写明左右位置（「画面左侧的A」「画面右侧的B」）
- 不要把两个人的外貌描述堆在一起，AI 会把五官服装混着画
- 脚本按 characters 字段顺序自动加「画面左侧/画面右侧」锚定

### 5. 用参考图锁定（进阶）
在即梦/LiblibAI 平台实操时：
1. 先用角色卡的外貌锁词生成一张「定妆照」（正面、半身、光线均匀）
2. 后续每个镜头用「角色参考/图生图」功能，把这张定妆照作为参考图
3. 参考图权重建议 0.5-0.7（太高会限制动作，太低保不住脸）

## 常见一致性翻车点

| 翻车现象 | 原因 | 修正方案 |
|----------|------|----------|
| 每镜头脸不一样 | 没有角色卡，每次自由描述 | 强制使用角色卡锁词 + 参考图 |
| 发色忽深忽浅 | 描述时加了模糊词（如「深色头发」） | 精确到颜色：纯黑 / 深棕 / 亚麻金 |
| 服装细节变来变去 | 只写大类（如「裙子」） | 写清楚颜色、款式、材质、配饰 |
| 年龄感漂移 | 没有年龄锚点 | 角色卡里写死「20岁左右的年轻女性」 |
| 身高体型变化 | 没写体型描述 | 加体型锁词：纤细 / 丰满 / 健壮 / 挺拔 |

---

## 配角处理

- 主要角色（有台词、有特写）：必须做完整角色卡
- 次要角色（路人、背景板）：可以简化，只写大类特征（如「穿西装的中年男性路人」），不需要精细锁词
- 不要给每个路人都做完整角色卡——浪费 token，也没必要
