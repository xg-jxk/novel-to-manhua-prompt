## 甜宠言情

**画风**：韩漫唯美风，厚涂质感，皮肤通透，眼睛大而闪亮
**光影**：暖色调，柔光，浅景深，逆光发丝金边
**色调**：粉橘色系、奶咖色系，低对比度，柔和
**镜头节奏**：慢，多用特写放大心动瞬间
**常用运镜**：缓慢推近、微微环绕
**提示词追加后缀**：
```
唯美韩漫风格，厚涂质感，皮肤通透细腻，大眼睛闪亮，粉嫩腮红，柔和暖光，浅景深，浪漫氛围
```

## 战神/逆袭爽文

**画风**：国漫半写实风，硬朗线条，高对比度
**光影**：硬光，明暗对比强烈，侧光突出轮廓
**色调**：冷灰蓝、黑金、暗红，高对比度，高饱和重点色
**镜头节奏**：快，动作戏利落，爽点给慢动作特写
**常用运镜**：低角度仰拍、快速推近、环绕
**提示词追加后缀**：
```
国漫半写实风格，硬朗线条，高对比度电影感，侧逆光勾勒轮廓，冷峻色调，霸气氛围
```

## 悬疑/惊悚

**画风**：写实偏暗，低饱和，颗粒质感
**光影**：低调照明，单光源，大面积阴影，局部打光
**色调**：灰蓝、墨绿、暗红，低饱和，高对比度
**镜头节奏**：忽快忽慢，关键信息给长时间静止特写
**常用运镜**：缓慢推近、手持微晃、突然静止
**提示词追加后缀**：
```
写实电影感，低调照明，大面积阴影，冷色调，低饱和度，悬疑压抑氛围，胶片颗粒感
```

## 古风/仙侠

**画风**：国风水墨+CG结合，飘逸唯美
**光影**：柔光，丁达尔效应，仙气缭绕
**色调**：青白色、烟紫色、水墨灰，清雅淡远
**镜头节奏**：飘逸缓慢，多用大全景展现仙气
**常用运镜**：升降镜头、缓慢横移、环绕
**提示词追加后缀**：
```
国风水墨仙侠风格，飘逸唯美，衣袂飘飘，丁达尔光效，仙气缭绕，淡彩水墨质感
```

## 都市职场

**画风**：写实韩漫，干练精致
**光影**：自然光为主，办公室荧光灯+落地窗自然光
**色调**：冷灰白、莫兰迪色系，干净清爽
**镜头节奏**：中等，对话为主，节奏利落
**常用运镜**：固定镜头、过肩镜头、缓慢推近
**提示词追加后缀**：
```
都市写实韩漫风格，精致干练，现代都市场景，干净构图，自然光线，高级感色调
```

## 校园青春

**画风**：日系赛璐璐，清新明亮
**光影**：晴天自然光，逆光剪影，树影斑驳
**色调**：天蓝色、樱粉色、柠檬黄，高明度，高饱和但柔和
**镜头节奏**：轻快，多用动态镜头
**常用运镜**：跟镜头、横摇、快速切换
**提示词追加后缀**：
```
日系动漫风格，赛璐璐上色，清新明亮，青春校园感，阳光洒落，树影斑驳，治愈氛围
```

## 快速选择指南

拿到一段小说，先判断题材：
1. 有没有谈恋爱？→ 有 → 甜宠言情
2. 是不是主角被欺负后打脸？→ 是 → 战神/逆袭爽文
3. 有没有破案/鬼怪/阴谋？→ 有 → 悬疑/惊悚
4. 是不是古代/修仙/武侠？→ 是 → 古风/仙侠
5. 是不是现代办公室？→ 是 → 都市职场
6. 是不是学校里的故事？→ 是 → 校园青春

混合题材时，以**主情绪**为准。比如「都市+甜宠」，主情绪是甜，就用甜宠模板。
