## 出图提示词结构（关键帧）

即梦/LiblibAI 对自然语言描述友好，不需要复杂的 `()` 权重语法。按以下顺序组织，效果最佳：

```
[画幅比例], [景别], [画面主体描述], [角色外貌锁词], [角色动作表情], [场景环境], [光影氛围], [画风质感]
```

### 各部分写法

**1. 画幅比例**
- 竖屏短剧：`竖屏构图，9:16比例`
- 横屏：`横屏构图，16:9比例`

**2. 景别**
- 直接用中文术语：`远景全景` / `中近景` / `面部特写` / `大特写`
- 补充视角：`俯视角度` / `仰视角度` / `平视角度` / `过肩镜头` / `第一人称视角`

**3. 角色外貌锁词**（从角色卡原样复制，禁止改写）
- 示例：`年轻女性，约20岁，黑色长直发，齐刘海，丹凤眼，鹅蛋脸，皮肤白皙，穿白色连衣裙`

**4. 角色动作表情**
- 具体、可视觉化：`微微侧头，嘴角上扬，眼神温柔看向镜头方向`
- 避免抽象：不要写「很开心」，写「眼睛弯成月牙，嘴角上扬露出微笑」

**5. 场景环境**
- 具体到物体和材质：`现代都市写字楼办公室，落地玻璃窗，窗外是黄昏的城市天际线，办公桌后有书架`
- 避免空泛：不要写「一个房间」，写清楚是什么房间、有什么东西

**6. 光影氛围**
- 光的方向 + 色温 + 情绪：`侧逆光，暖金色调，柔和氛围光，丁达尔效应`
- 常见组合：
  - 甜蜜：`暖光，柔和漫射，浅景深`
  - 紧张：`硬光，高对比度，冷色调`
  - 悲伤：`阴天柔光，灰蓝色调，低饱和`
  - 悬疑：`低调照明，明暗对比强烈，单光源`

**7. 画风质感**
- 漫剧常用：
  - `国漫风格，精致CG渲染，半写实，高清细节`
  - `日系动漫风格，赛璐璐上色，线条清晰`
  - `韩漫风格，厚涂质感，唯美写实`
  - `写实电影感，真人质感，胶片色调`

## 出视频提示词结构（动态镜头）

视频提示词在出图关键帧的基础上，增加**运镜动态**和**动作节奏**描述。

```
[在出图提示词基础上], [运镜方式], [角色动态动作], [运动节奏]
```

### 运镜描述（即梦/可灵友好）
- 推镜头：`镜头缓慢向前推进，逐渐聚焦到角色面部`
- 拉镜头：`镜头向后拉远，展现整个环境`
- 摇镜头：`镜头从左向右缓慢摇动`
- 跟镜头：`镜头跟随角色向后移动，保持角色在画面中心`
- 环绕：`镜头围绕角色缓慢环绕一周`
- 升降：`镜头缓慢上升，从平视变为俯视`
- 手持：`手持摄影，轻微晃动，增加临场感`

### 动作动态描述
- 具体到肢体动作的起止：`角色缓缓抬起头，眼神从低垂变为坚定`
- 节奏控制：`动作缓慢，情绪递进` / `动作快速，紧张急促`
- 微表情变化：`嘴角微微上扬，眼角带笑`

## 即梦平台适配要点

1. **自然语言优先**：即梦对长段自然语言理解很好，不需要用逗号拆分关键词。可以写成通顺的句子。
2. **负面提示词**：即梦支持独立的负面提示词输入框，把 `references/negative-prompts.md` 里的内容贴进去即可。
3. **参考图功能**：即梦支持图生图/角色参考。生成角色卡后，先出一张角色定妆照，后续镜头用「角色参考」功能锁定。
4. **画幅选择**：在平台界面选择 9:16 竖屏比例即可，提示词里不用再写尺寸。

## LiblibAI 平台适配要点

1. **关键词式提示词**：LiblibAI 基于 Stable Diffusion 体系，更适合用逗号分隔的关键词列表，而不是长句。
2. **权重语法**：需要强调的部分用 `()` 加重，如 `(精致五官:1.2)`
3. **负面提示词**：LiblibAI 有独立的 Negative Prompt 输入框。
4. **模型选择**：提示词风格要匹配你选的底模（国风模型用国风词，二次元模型用二次元词）。

## 通用拼接公式

每条完整的出图提示词按此公式组装：

```
[比例声明], [景别+视角], [角色外貌锁词], [当前动作表情], [场景环境细节], [光影氛围], [画风质感], [质量增强词]
```

质量增强词（通用，放在最后）：
`masterpiece, best quality, highly detailed, 8k, ultra-detailed`

```

负面提示词：
（复制到负面提示词输入框）
低质量, 模糊, 畸形手指, 多余肢体, 面部崩坏, 变形, 水印, 文字, 签名
```
