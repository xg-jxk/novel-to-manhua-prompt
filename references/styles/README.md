# 画风模板目录

本目录存放所有画风模板。每种画风一个 md 文件。

## 文件命名规则

- 中文命名，如：`3D次时代建模.md`、`日系二次元.md`、`韩漫厚涂.md`、`写实电影感.md`

## 每个画风 md 必含字段

1. **视觉关键词**：Liblib 权重词 / 即梦中文描述
2. **负面词追加**：排除其他画风的词
3. **色彩倾向**：皮肤/头发/眼睛/整体色调
4. **镜头质感**：景深/打光/材质特点

## 如何新增画风

1. 参考 `3D次时代建模.md` 的结构
2. 写新画风的关键词、负面词、色彩倾向
3. 放到本目录即可，SKILL.md 会自动索引
