# LiblibAI 视频提示词规范

> 适用：LiblibAI 平台上的视频模型（可灵 Kling / Vidu / Runway Gen-3）。
> 提示词语言：**中文描述性长句**，不用英文关键词权重堆砌。

---

## 平台基础参数

| 项 | 值 |
|----|-----|
| 接入模型 | 可灵 Kling / Vidu / Runway Gen-3 |
| 时长 | 5s / 10s / 15s |
| 比例 | 默认 16:9 / 9:16 / 1:1 |
| 负面提示词 | 响应强，必加 |
| 提示词语言 | 中文描述长句，模型理解好 |
| 参考图 | 支持多图参考（人物+道具+场景） |

---

## 提示词结构（5 段式）

```
[运镜 1 句] + [动作起止 1-2 句] + [微表情/细节 1 句] + [节奏词] + [稳定性约束]
```

**写法顺序**（重要度从高到低）：
1. 核心动作（放最前面，模型先抓重点）
2. 人物状态（外貌/服装引用参考图）
3. 场景环境
4. 运镜方式
5. 稳定性约束（放最后）

---

## 运镜词库

| 运镜 | 提示词写法 |
|------|-----------|
| 固定 | 镜头固定不动，机位稳定 |
| 缓慢推近 | 镜头缓慢向前推进，逐渐聚焦到角色面部 |
| 快速推近 | 镜头快速向前推近，骤然聚焦 |
| 拉远 | 镜头缓慢向后拉远，展现环境 |
| 左摇 | 镜头从右向左缓慢摇动 |
| 右摇 | 镜头从左向右缓慢摇动 |
| 跟拍 | 镜头跟随角色向前移动，保持角色在画面中心 |
| 低角度仰拍 | 低角度仰拍镜头 |
| 环绕 | 镜头围绕角色缓慢环绕半周 |
| 手持 | 手持摄影，轻微晃动，临场感 |
| 骤停 | 镜头骤然静止，时间凝固感 |
| 慢动作 | 慢动作镜头，动作节奏放缓 |

---

## 说话状态写法（有台词必加）

- 嘶吼：角色张嘴嘶吼，表情凶狠
- 对话：角色嘴唇自然开合，像在说话
- 低语：角色低声说话，嘴唇微动
- 哭喊：角色泪流满面，张嘴哭喊
- 喘气：角色胸口剧烈起伏，大口喘气

---

## 节奏词（结尾）

- 对话/情绪戏：动作缓慢柔和
- 紧张戏：节奏急促
- 动作戏：动作利落有力
- 静态戏：安静沉静

---

## 稳定性约束（结尾必加）

```
人物面部保持稳定，不换脸，不畸变，肢体动作自然，背景不发生突变，无跳帧，无多余肢体。
```
