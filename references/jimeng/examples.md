# 即梦 Dreamina 视频提示词示例集

---

## 示例 1：情绪特写（5s）

```
镜头缓慢向前推近。角色原本垂着眼帘沉默，缓缓抬眼看向对面，眉头缓缓皱紧，后槽牙咬紧，垂在身侧的拳头慢慢握紧又松开，喉结轻轻滚动一下。动作缓慢沉重，悲壮压抑。人物面部保持稳定，不换脸，不畸变，肢体动作自然，背景不发生突变，无跳帧，无多余肢体。
```

---

## 示例 2：震惊反转（5s）

```
镜头骤然静止。角色的眼睛缓缓睁大，瞳孔微微收缩，睫毛轻颤，一滴眼泪从眼角慢慢滑落，整个画面时间凝固。动作缓慢，震惊错愕的情绪。人物面部稳定，不换脸，无画面闪烁。
```

---

## 示例 3：对话戏（5s）

```
镜头固定不动。角色嘴唇自然开合，像在认真说话，眉头微微皱起，头轻轻摇了一下，手在身侧微微比划。动作自然流畅。人物面部保持稳定，不换脸，口型与说话自然对应，背景不突变，无跳帧。
```

---

## 示例 4：动作戏-飞踢（8s）

```
低角度仰拍，慢动作镜头。角色戴着手铐猛地向前冲出，右腿高高抬起，狠狠踹在对面男子胸口，对面男子身体向后倒飞出去数米摔在地上，口中喷出一口鲜血，张嘴惨叫。动作先快后慢，爽感爆发。人物面部保持稳定，动作流畅物理合理，无穿模，无肢体穿插，背景不发生突变。
```

---

## 示例 5：行走跟拍（5s）

```
镜头跟随角色向前移动，保持角色在画面中心。角色戴着手铐，脚步沉重地一步步向前走，头微微低垂，背影在昏暗走廊中显得孤独。动作缓慢沉重。人物面部保持稳定，不换脸，肢体动作自然，背景不突变，无跳帧。
```
