# 题材模板目录

本目录存放所有题材模板。每个题材一个 md 文件。

## 文件命名规则

- 中文命名，如：`穿书反派恋爱养成.md`、`战神逆袭.md`、`悬疑探案.md`
- 以 `_` 开头的是兜底/特殊文件，如：`_通用.md`

## 每个题材 md 必含字段

1. **核心场景类型**：这个题材常见的 5-8 种场景，对应景别和情绪
2. **角色关系锚定**：主角/配角/反派的典型状态
3. **提示词追加后缀**：Liblib 权重词 / 即梦中文描述
4. **节奏建议**：镜头时长分配、运镜偏好

## 如何新增题材

1. 复制 `_通用.md` 作为模板
2. 改名成新题材名
3. 填充该题材特有的场景类型、情绪词、提示词后缀
4. 放到本目录即可，SKILL.md 会自动索引

## 自动识别逻辑

用户选"自动识别"时，AI 读完小说后：
1. 提取题材关键词（穿书/反派/恋爱/战神/悬疑/古风...）
2. 在本目录找匹配的 md 文件
3. 找到 → 用对应模板
4. 没找到 → 用 `_通用.md` 兜底
