# 镜头时长分配指南

> 根据场景类型、节奏类型、台词长度三个维度，灵活分配每段时长。不是固定 3s 一段。

---

## 总原则

- **单段视频上限 15s**，根据信息量决定实际时长
- 短的戏 8-10s，信息量大的 12-15s
- 每段时长跟着情绪走：紧张时快切，情绪到位时慢下来
- 不平均分配：一段 15s 里有快有慢才有节奏

---

## 维度一：按场景类型分配

| 场景类型 | 单段时长 | 运镜特点 | 例子 |
|----------|---------|----------|------|
| 快切反应镜头 | 1-2s | 骤停/定格 | 震惊转头、拼命摇头、瞳孔收缩 |
| 对话戏 | 3-4s | 固定机位，缓慢微推 | 放狠话、冷静回应、对峙对话 |
| 动作戏 | 3-5s | 手持晃动/跟拍/慢动作 | 踹门闯入、飞踢反杀、高跟鞋踩脚 |
| 情绪特写 | 4-6s | 缓慢推近/环绕 | 哭骂、对视、内心挣扎 |
| 出场/反转 | 5-8s | 低角度仰拍+慢动作+推近 | 逆光登场、道具砸脸、掏出引爆器 |
| 转场空镜 | 2-3s | 缓慢拉远 | 仓房外景、海边远景、环境交代 |

---

## 维度二：按节奏类型分配

### 快节奏（紧张/动作/反转）
- 平均单段 2-3s
- 多切反应镜头（1-2s）
- 总时长压缩在 8-10s
- 例：打斗戏、追逐戏、反转揭露

### 中节奏（对话/日常/推进）
- 平均单段 3-4s
- 对话正反打交替
- 总时长 10-12s
- 例：对峙对话、信息交代、人物互动

### 慢节奏（情绪/心动/悲伤）
- 平均单段 4-6s
- 多给特写和缓慢推近
- 总时长 12-15s
- 例：哭戏、心动瞬间、告别、内心独白

---

## 维度三：按台词长度分配

| 台词类型 | 单段时长 | 说明 | 例子 |
|----------|---------|------|------|
| 无台词（纯动作/情绪） | 2-5s | 按动作节奏走，动作做完就切 | 踹门、飞踢、对视流泪 |
| 单字/短叹词 | 1-2s | 一声惨叫、一个"嗯" | "啊！""哼。" |
| 短句台词（1-2 句） | 3-4s | 正常对话节奏 | "别过来！""你放了她。" |
| 长台词（3-5 句） | 5-7s | 需要给说话时间，运镜缓慢推近 | 反派长篇大论、角色哭着控诉 |
| 正反打对话（2 人交替） | 每句 3s | 你一句我一句，各占一段 | 对峙对话、争吵 |
| 内心 OS / 旁白 | 比台词多 1-2s | 需要给观众消化情绪 | 主角内心吐槽、系统提示 |

---

## 组合判断公式

一段时长 = **场景类型时长** + **台词长度修正**

例：
- 对话戏 + 短句台词 = 3-4s（标准）
- 对话戏 + 长台词（5 句）= 5-7s（加 2-3s）
- 动作戏 + 无台词 = 3-5s（标准动作时长）
- 动作戏 + 惨叫一声 = 2-3s（动作做完+惨叫就切）
- 情绪特写 + 哭骂长台词 = 6-8s（情绪+台词都给足）

---

## 分配技巧

### 1. 情绪升级时，景别收紧 + 时长拉长
情绪递进：冷静 → 紧张 → 激动 → 爆发
对应时长：3s → 3s → 4s → 5s

### 2. 动作戏快切，反应镜头短
动作本身 3-4s，动作后的反应镜头 1-2s 就够了。
例：飞踢（3s）→ 倒飞落地（2s）→ 站定（1s）

### 3. 心动瞬间要给足时间
恋爱题材的心动/脸红/对视，观众需要时间消化情绪。
比正常对话戏多给 1-2s。

### 4. 不要平均分配
不要所有段都写 3s。有快有慢才有节奏。
一段 15s：1s + 3s + 5s + 2s + 4s = 15s，比全 3s 有张力。

---

## 检查清单

分配完时长后检查：
- [ ] 总时长是否 ≤15s？
- [ ] 有没有哪段太长（超过 8s）？是不是该拆成两段？
- [ ] 有没有哪段太短（不到 1s）？是不是该合并？
- [ ] 节奏有没有起伏？还是从头到尾一个速度？
- [ ] 情绪高点有没有给足时长？
- [ ] 长台词有没有给够时间？（5 句话至少 6s）
- [ ] 短叹词有没有拖太长？（"啊！"1-2s 就够）
